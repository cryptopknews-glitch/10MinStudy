# 10MinStudy

## Student 10-Minute Study Helper

10MinStudy is a fast, student-focused study assistant for Class 9–12 students, starting with Class 9–10.

### Initial MVP

- Math
- Physics
- Chemistry
- English

### Project direction

10MinStudy will combine deterministic study tools, AI assistance, and curriculum-aware retrieval to help students solve, understand, summarize, and prepare answers faster.

### Development phases

1. Foundation
2. UI/UX
3. AI Core
4. Smart Tools
5. Curriculum + RAG
6. Student Features
7. Image Homework Solver
8. Admin
9. SEO + Growth
10. Monetization + Production

### Privacy

The product is designed with privacy-first processing and secure handling of student data in mind.
